# Predicción de Popularidad de Canciones - Kaggle

Este repositorio contiene el desarrollo de mi trabajo para una competencia de Kaggle de la materia **82.05 - Análisis Predictivo**.

El objetivo fue predecir la popularidad de canciones a partir de sus características numéricas y categóricas.

Durante el proyecto se realizaron:

- Análisis exploratorio de datos (EDA)
- Tratamiento de outliers y análisis de *data drift*
- Feature engineering
- Entrenamiento y comparación de distintos modelos (RLM, Regresión Ridge, SVM, KNN, Random Forest, Rotation Forest, ExtraTrees, XGBoost, LightGBM, TabNet, AdaBoost, CatBoost, entre otros)
- Optimización de hiperparámetros
- Análisis de predicciones y submissions previas
- Construcción de un ensamble final para mejorar el desempeño en Kaggle

El repositorio incluye los notebooks utilizados durante el desarrollo, junto con las pruebas realizadas y las versiones finales del modelo.
